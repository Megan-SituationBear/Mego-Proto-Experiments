AIInput Component States

Visual reference for all component states and variations

💡 Tip: Hover over the + icon to see the Conversation Context menu. You can move your mouse to the menu and it will stay open!

🔓 Logged Out States (Home Page)

State 1: Default
User hasn't interacted with input yet

Conversation Context:

State 2: Focused
User has clicked into the input (no messages sent yet)
State 3: Focused with Conversation
User has an active conversation and is typing a new message

🔐 Logged In States (Home Page)

State 4: Default (Logged In)
Logged in user on home page, input at rest
State 5: Focused (Logged In)
Logged in user typing (no conversation yet)
State 6: Focused with Conversation (Logged In)
Logged in user with active conversation

💼 Workspace/Context Page States

State 7: Default (Workspace)
Input in workspace/context page at rest
State 8: Focused (Workspace)
User typing in workspace
State 9: Focused with Conversation (Workspace)
Active conversation in workspace
