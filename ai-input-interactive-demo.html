AIInput Component - 3 Variants

Click to focus → Type → Press Enter → Try adding integrations from the + menu

VARIANT 1

AI Input - Logged Out

Default: 48px
Focused: 120px

📍 When to use: Landing pages, marketing pages, logged-out experience

🔒 No settings button - users must log in first

Conversation Context:

How to Install

import { AIInput, ConversationMessage } from './components/ui'; <AIInput placeholder="Try: @Copado what do you do?" onSendMessage={handleSendMessage} messages={messages} showTypingIndicator={isTyping} isLoggedIn={false} pageContext="home" hasConversation={messages.length > 0} />
VARIANT 2

AI Input - Home Page (Logged In)

Default: 48px
Focused: 100px
+ Conversation: 140px

📍 When to use: Dashboard home page, logged-in welcome screen

🧪 Test Integration Flows:

  • 1. Click + button → Select "Connect Slack Channel"
  • 2. Paste: https://workspace.slack.com/archives/C1234ABCD
  • 3. See auto-extracted channel name → Confirm → Chip appears!
  • 4. Try Jira (not connected) - it will ask you to set up in Settings first
  • 5. Go to Settings (⚙️ button) → Click Jira to connect it → Try adding a ticket
  • 6. Test URLs: PROJ-456 or Sprint-12

Conversation Context:

How to Install

import { AIInput, ConversationMessage } from './components/ui'; <AIInput placeholder="What would you like to work on today?" onSendMessage={handleSendMessage} messages={messages} showTypingIndicator={isTyping} isLoggedIn={true} pageContext="home" hasConversation={messages.length > 0} />
VARIANT 3

AI Input - Context Page (Workspace)

Default: 48px
Focused: 80px
+ Conversation: 120px

📍 When to use: Workspace pages, project pages, chat panels

🧪 Test "Context For This Work":

  • 1. Notice the + menu says "Context For This Work" (not "Conversation Context")
  • 2. Add Confluence doc: https://confluence.com/pages/12345/API-Documentation
  • 3. Try Org connection → Authenticate → Choose sandbox
  • 4. Settings button shows "Settings For This Work"
  • 5. All context is specific to this workspace/project
