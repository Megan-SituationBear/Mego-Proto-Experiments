# Copado AI Landing Page

A beautiful, responsive landing page featuring an AI-powered input interface built with React and Tailwind CSS.

## Getting Started

1. Install dependencies:
```bash
   npm install
```

2. Start the development server:
```bash
   npm start
```

3. Open [http://localhost:3000](http://localhost:3000)

## Build for Production
```bash
npm run build
```
